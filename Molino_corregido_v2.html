Funcionamiento

RESULTADO REPORTADO POR EL ARTÍCULO
El análisis estructural del artículo se realizó mediante ANSYS. Por ello, el esfuerzo equivalente máximo y la deformación total se muestran como resultados del análisis numérico, mientras que las ecuaciones mostradas aquí permiten visualizar los cálculos mecánicos que sí pueden reproducirse directamente en el modelo HTML.

1. Fuerza de impacto

P Δt = m Δv
P = m(v₁ − v₂) / Δt
P = 0.00493 × (85.2 − 45.6) / 0.001
P = 195.2 N

2. Esfuerzo nominal de referencia

Para visualizar la relación entre la fuerza de impacto y el área efectiva del martillo se calcula un esfuerzo nominal de referencia:

σnom = P / A
σnom = 195.2 N / 348 mm²
σnom = 0.56 MPa

Análisis de fatiga — módulo complementario

Importante: El artículo base no presenta una curva S-N ni una vida a fatiga. Por ello, esta sección se presenta como un análisis complementario académico y no como un resultado obtenido por los autores del artículo.

Parámetros utilizados

Esfuerzo máximo 26.37 MPa
Esfuerzo mínimo asumido 0 MPa
Límite elástico 355 MPa
Límite de resistencia Se 177.50 MPa
Esfuerzo alternante 13.19 MPa
Esfuerzo medio 13.19 MPa

1. Esfuerzo alternante

σa = (σmax − σmin) / 2
σa = (26.37 − 0) / 2
σa = 13.19 MPa

2. Esfuerzo medio

σm = (σmax + σmin) / 2
σm = (26.37 + 0) / 2
σm = 13.19 MPa

3. Límite de resistencia utilizado

Se ≈ 0.5 σy
Se = 0.5 × 355
Se = 177.50 MPa
Este valor se utiliza únicamente como supuesto académico conservador para poder mostrar el procedimiento de fatiga. No corresponde a una curva S-N presentada en el artículo.

4. Criterio de Soderberg

σa/Se + σm/σy ≤ 1
13.19 / 177.50 + 13.19 / 355 = 0.1115
Utilización = 0.1115

5. Factor de seguridad a fatiga

nf = 1 / [ σa/Se + σm/σy ]
nf = 1 / 0.1115
nf = 8.97
Resultado del módulo complementario: El criterio de Soderberg calculado con los supuestos indicados produce un factor de seguridad a fatiga de aproximadamente 8.97 .

Este resultado no representa una vida exacta en ciclos. Para obtener una vida a fatiga real sería necesario disponer de propiedades S-N experimentales del acero 45#, condiciones de superficie, concentración de esfuerzos, tipo de carga y características reales del ciclo de trabajo.

Gráfica — Criterio de Soderberg

La gráfica representa la relación entre esfuerzo medio y esfuerzo alternante. El punto de operación se compara con la línea límite del criterio de Soderberg.

Interpretación del modelo

1. Los parámetros A, B y C permiten modificar visualmente la geometría del martillo.

2. La velocidad del rotor modifica directamente la velocidad angular y la frecuencia calculada.

3. La fuerza de impacto se calcula mediante el principio impulso-cantidad de movimiento.

4. El esfuerzo máximo de 26.37 MPa y la deformación total de 31.9 μm corresponden a los resultados de ANSYS reportados por el artículo.

5. El factor de seguridad estático se calcula en este modelo mediante la relación entre el límite elástico y el esfuerzo máximo.

6. El módulo de fatiga es complementario y utiliza supuestos explícitos para mostrar el procedimiento matemático. No se atribuye al artículo una vida a fatiga que este no reporta.
